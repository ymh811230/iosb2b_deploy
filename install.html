⚠️ 설치 안내

1. 반드시 Safari 브라우저에서 실행해 주세요.

2. '설치' 팝업이 뜨면 확인을 누르고 홈 화면을 확인하세요.

3. 실행 시 '신뢰할 수 없는 개발자' 오류가 발생하면:
  → 설정 > 일반 > VPN 및 기기 관리에서 해당 개발자를 '신뢰'로 설정해야 합니다.

등록된 UDID만 설치 가능합니다. UDID를 kdp99로 알려주시면 등록해서 설치 가능하도록 해드리겠습니다.

UDID 복사 방법

1. Mac 또는 Windows PC에 iPhone을 연결하세요. 가장 정확한 방법입니다.

2. Mac (macOS 10.15 이상): Finder에서 연결된 iPhone을 선택한 후, 기기 이름 아래 모델명을 한 번 클릭하면 UDID가 나타납니다.
   → 클릭할 때마다 정보가 바뀌며, 마우스 오른쪽 버튼으로 복사할 수 있습니다.

3. Windows 또는 이전 버전 Mac: iTunes를 실행하고 기기 모양 아이콘을 클릭합니다.
   → '요약' 탭에서 일련 번호(Serial Number)를 클릭하면 UDID로 바뀝니다. 마우스 오른쪽 버튼으로 복사하세요.
